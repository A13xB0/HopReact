Know when your repeater goes quiet

Tell HopReact which MeshCore repeaters and observers are yours, choose how many hours of silence means trouble, and the bot will send you a Discord DM when one stops being seen.

It watches the same public CoreScope data the coverage map uses. There is no email address and no password involved — signing in with Discord is the whole account.

Sign in with Discord

How the alerts behave

  • One message when it goes down, one when it returns. A node that stays down for a week doesn't message you every five minutes.
  • Nothing for something already broken. Add a watch to a node that is already quiet and you get no alert — you knew.
  • Not heard is the default signal. You can additionally alert on stopped relaying for a node that should be carrying traffic.
  • Quiet during an outage of ours. If the upstream data looks broken or frozen, HopReact says nothing rather than telling everyone their whole network died.

One thing to know

A Discord bot can only DM someone it shares a server with, so signing in adds you to the {{.Cfg.Site.Name}} Discord. Stay in it — leaving silently stops the alerts arriving.
